# Marvel Checklist

An interactive, mobile-friendly checklist of the MCU movies and shows.
Tap an item to mark it watched — your progress is saved in your own
browser (nothing is sent anywhere or shared with other visitors).

**Live page:** add your GitHub Pages link here once it's enabled, e.g.
`https://YOUR-USERNAME.github.io/mcu-checklist/`

## About

Built as a simple single-file HTML/CSS/JS page — no build step, no
dependencies, no backend. Just open `index.html` in a browser, or visit
the hosted link above.
